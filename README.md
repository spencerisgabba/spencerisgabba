# Spencer Schmidt

Full-stack software engineer building web applications for music, creative, and community-driven platforms. B.S. Computer Science from Southern New Hampshire University.

## What I'm Working On

**[Three Seeds](https://github.com/spencerisgabba)** — Music recommendation engine that takes three seed artists and returns ranked album suggestions using TF-IDF tag weighting, cosine similarity, and critic/crowd score normalization. Built with Next.js and TypeScript.

**[FastStats](https://github.com/spencerisgabba)** — Mobile-first progressive web app for real-time sports data. Consumes ESPN's public API and renders standings, scores, and player stats with offline support via service workers. Built with Vite and React.

**[Album Review Platform](https://github.com/spencerisgabba)** — Full-stack music review site with OAuth authentication, MongoDB persistence, and live Spotify API integration.

**Violin Guild of America** — Freelance full-stack development for a nationwide music community: auth flows, admin tooling, SEO, and content management.
